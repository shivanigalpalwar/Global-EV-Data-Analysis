# Global-EV-Data-Analysis

Developed an interactive Power BI dashboard using the IEA Global EV Data 2024 dataset to analyze global electric vehicle (EV) sales, stock, and energy consumption trends. The project explores regional growth patterns, powertrain categories (BEV, PHEV, and FCEV), vehicle modes, and changes over time.

Key Highlights:

Analyzed EV sales and stock trends across different regions.
Compared powertrain technologies and passenger and freight vehicle modes.
Explored energy consumption using parameters and measurement units.
Identified trends and patterns using time-series and comparative analysis.
Created interactive dashboards using Power BI visuals, slicers, and filters.
Used DAX for calculated columns and data analysis.
